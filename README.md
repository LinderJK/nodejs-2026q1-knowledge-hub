# Knowledge Hub

**NestJS** REST API for users, articles, categories, and comments. Data is kept **in memory** (in-memory store). **Swagger** documents the endpoints.

## Requirements

- **Node.js** ≥ 24.10

## Quick start

```bash
npm install
npm run start:dev
```

Server: `http://localhost:4000` (override with the `PORT` env variable).

Swagger UI: `http://localhost:4000/doc`

Build and production run:

```bash
npm run build
npm run start:prod
```

## Tests

```bash
npm test
```
